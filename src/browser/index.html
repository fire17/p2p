What the infrastructure sees: an opaque hash and encrypted frames — never your identity, never your messages. The public trackers, STUN, and WebRTC's own DTLS are all treated as hostile: the security comes from the commitment in your key plus the Noise IK handshake that runs on top of them. The honest caveat: this page is code served from a web origin, so you are trusting whoever serves it. For the strongest guarantee, run the CLI.
