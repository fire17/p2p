Chat that needs no server.

p2p is a tiny, zero-dependency chat framework. One 26-character key is your whole contact surface — send it to a friend, they find you and message you: direct, end-to-end encrypted, provably MITM-proof on first contact, through NAT, with no coordinator server of ours.

  • No server Rendezvous rides free public infrastructure — mDNS, the BitTorrent DHT, public trackers.
  • MITM-proof Your key commits to your identity keys. The first message that decrypts is the proof.
  • Zero deps Node built-ins only. Nothing to audit but us.

Install

curl -fsSL https://p2p.akeyo.io/init | sh
irm https://p2p.akeyo.io/init.ps1 | iex

Already have p2p? Just run p2p

  1. Run the installer. It puts the p2p command on your machine — no account, no signup.
  2. Get your key. p2p key prints your 26 characters. That string is you.
  3. Chat. Send the key to a friend; they run p2p <key> and you’re talking — directly.
