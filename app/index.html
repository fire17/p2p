What the infrastructure sees: an opaque hash and encrypted frames — never your identity, never your messages. The public trackers, relays, STUN, and WebRTC’s own transport encryption are all treated as hostile: security comes from the commitment inside your key plus the Noise IK handshake that runs on top of them, exactly as the CLI does. The honest caveat: this page is code served from a web origin, so you are trusting whoever serves it. For the strongest guarantee, run the CLI.
